# Mohit Salwan — 3D Interactive Portfolio

An expressive, interactive 3D developer portfolio showcasing machine-learning systems, data engineering tools, and creative web experiments.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **UI & Interaction**: React 19, TypeScript
- **Styling**: Tailwind CSS + Custom High-Craft CSS (`app/globals.css`)
- **Animations & Smooth Scrolling**: Lenis (`@studio-freight/lenis`)
- **Icons**: Lucide React + Custom SVGs

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
